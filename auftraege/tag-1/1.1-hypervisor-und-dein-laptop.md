# Auftrag 1.1: Hypervisor und dein Laptop

Stand: 19.10.2026 · Zeit: 30 Min. · Form: Partnerarbeit

## Ziel
- Du kannst prüfen, ob dein Laptop virtuelle Maschinen (Virtual Machine) ausführen kann. (K3)
- Du kannst Hypervisoren dem Typ 1 oder Typ 2 zuordnen. (K2)

## Voraussetzungen
- Input «Was ist Virtualisierung?» gehört
- Theorie zum Nachlesen: [Kapitel 1 Virtualisierung](../../theorie/01-virtualisierung.md)

## Ausgangslage
Die «Velo Zürich AG» will Testserver als virtuelle Maschinen betreiben. Zuerst prüfst du, ob dein eigener Laptop das kann.

## Auftrag

### Schritt 1: Ist die Virtualisierung eingeschaltet?
Öffne den Task-Manager mit `Ctrl` + `Shift` + `Esc`. Klicke auf **Leistung** und dann auf **CPU**.

Schreibe in dein Lernjournal:

| Was | Wert auf deinem Laptop |
|-----|------------------------|
| Kerne | |
| Logische Prozessoren | |
| Virtualisierung | Aktiviert / Deaktiviert |

**Kontrolle:** Bei «Virtualisierung» steht **Aktiviert**. Steht dort «Deaktiviert», melde dich bei der Kursleitung.

### Schritt 2: Welches Windows hast du?
Öffne **PowerShell** (Startmenü > «PowerShell» eintippen). Gib diesen Befehl ein und drücke `Enter`:

```powershell
(Get-CimInstance Win32_OperatingSystem).Caption
```

Der Befehl zeigt den Namen deiner Windows-Version.

**Kontrolle:** Du siehst z. B. `Microsoft Windows 11 Pro` oder `Microsoft Windows 11 Education`. Notiere die Version.

> [!NOTE]
> Bei **Pro**, **Education** oder **Enterprise** ist der Hypervisor **Hyper-V** schon in Windows eingebaut. Bei **Home** fehlt er. Dann melde dich bei der Kursleitung.

### Schritt 3: Typ 1 oder Typ 2?
Ordne mit deinem Partner zu. Setze pro Zeile ein Kreuz.

| Produkt | Typ 1 (direkt auf der Hardware) | Typ 2 (Programm auf Windows/macOS) |
|---------|:-------------------------------:|:-----------------------------------:|
| VirtualBox | | |
| Microsoft Hyper-V | | |
| VMware ESXi | | |
| VMware Workstation | | |

### Schritt 4: Eine Frage zum Schluss
Welchen Hypervisor verwendet **Microsoft Azure**? Kreuze an.

- [ ] VirtualBox
- [ ] Hyper-V
- [ ] VMware Workstation
- [ ] KVM

## Erwartetes Ergebnis
Im Lernjournal:
- Tabelle aus Schritt 1 und deine Windows-Version
- Zuordnung aus Schritt 3 und Antwort aus Schritt 4

## Zusatzaufgabe ⭐
Hyper-V schaltest du unter Windows ein wie ein Programm. Trotzdem gilt es als Typ 1. Lies im Theorie-Kapitel nach und erkläre es in einem Satz.
