# Auftrag 1.1: Hypervisor und dein Laptop

Stand: 19.10.2026 · Zeit: 45 Min. · Form: Partnerarbeit

## Ziel
Du kannst Hypervisoren nach Typ 1 und Typ 2 einordnen und prüfen, ob dein Laptop für virtuelle Maschinen bereit ist. (K2)

## Ausgangslage
Die «Velo Zürich AG» will für ihre Lernenden Testserver betreiben. Bevor sie Hardware kauft oder in die Cloud geht, sollst du herausfinden, was dein eigener Laptop leisten kann.

## Auftrag

### Teil A: Ist dein Laptop bereit?
1. Öffne den Task-Manager (`Ctrl` + `Shift` + `Esc`) > **Leistung** > **CPU**.
   Notiere: Anzahl **Kerne**, **logische Prozessoren** und ob **Virtualisierung** «Aktiviert» ist.
2. Öffne PowerShell und führe aus:
   ```powershell
   systeminfo | Select-String "Hyper-V", "Gesamter physischer Speicher", "Total Physical Memory"
   ```
   Notiere den Arbeitsspeicher und was unter «Hyper-V-Anforderungen» steht.
3. **Kontrolle:** Wenn «Virtualisierung: Deaktiviert» steht, melde dich bei der Kursleitung. Dann muss die Virtualisierung im BIOS/UEFI eingeschaltet werden.

### Teil B: Hypervisoren einordnen
4. Recherchiert zu zweit und füllt die Tabelle aus:

   | Produkt | Typ 1 oder Typ 2? | Typischer Einsatz |
   |---------|-------------------|-------------------|
   | VirtualBox | | |
   | VMware Workstation | | |
   | Microsoft Hyper-V | | |
   | VMware ESXi | | |
   | KVM | | |
   | Proxmox VE | | |

5. Welchen Hypervisor nutzt Microsoft Azure? Schreibt einen Satz mit Quelle.

### Teil C: Rechnen
6. Eine VM braucht 2 vCPU und 2 GB RAM. Dein Windows braucht selbst etwa 4 GB.
   Wie viele solche VMs könntest du gleichzeitig auf deinem Laptop betreiben? Begründe.
7. Was bedeutet **Überbuchung** (Overcommitment) bei CPU und RAM? Warum ist sie bei CPU eher möglich als bei RAM?
