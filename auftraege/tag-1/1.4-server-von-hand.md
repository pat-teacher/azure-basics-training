# Auftrag 1.4: Einen Server von Hand einrichten

Zeit: 25 Min. · Form: Einzelarbeit

## Ziel
- Du kannst in einer VM Programme installieren und eine Datei anlegen. (K3)
- Du kannst beschreiben, warum das Einrichten von Hand bei vielen Servern aufwendig ist. (K2)

## Voraussetzungen
- Auftrag 1.2 erledigt, Multipass läuft
- eine Stoppuhr (Handy oder Windows-App «Uhr»)

## Ausgangslage
Die «Velo Zürich AG» braucht 10 gleiche Testserver. Auf jedem sollen zwei Programme installiert sein und eine Info-Datei liegen:
- `tree` zeigt Ordner und Dateien als Baum.
- `htop` zeigt die laufenden Programme, ähnlich wie der Task-Manager unter Windows.

Du richtest heute **einen** dieser Server von Hand ein und misst, wie lange du brauchst. Im nächsten Auftrag (1.5) macht ein Werkzeug genau dasselbe automatisch. Dann vergleichst du.

## Auftrag

### Schritt 1: Stoppuhr starten und VM erstellen
Starte die Stoppuhr **jetzt**. Erstelle dann in PowerShell eine neue VM:
```powershell
multipass launch --name hand
```
**Kontrolle:** `Launched: hand`

### Schritt 2: In die VM wechseln
```powershell
multipass shell hand
```
**Kontrolle:** Die Eingabezeile lautet `ubuntu@hand:~$`. Du bist jetzt in Ubuntu.

### Schritt 3: Paketliste aktualisieren
Unter Ubuntu installierst du Programme mit der **Paketverwaltung** `apt`. Sie lädt Programme (Pakete) aus dem Internet. Zuerst holt sie die aktuelle Liste aller Pakete:
```bash
sudo apt update
```
`sudo` führt den Befehl mit Administratorrechten aus. Ohne `sudo` darfst du nichts installieren.

**Kontrolle:** Die Ausgabe enthält `Reading package lists... Done`. Keine Zeile beginnt mit `E:` (E steht für Error).

### Schritt 4: Programme installieren
```bash
sudo apt install -y tree htop
tree --version
```
`install` installiert die genannten Pakete. `-y` beantwortet die Rückfrage «Do you want to continue?» automatisch mit Ja.

**Kontrolle:** `tree --version` zeigt eine Versionsnummer, z. B. `tree v2.1.1`.

### Schritt 5: Die Info-Datei anlegen
`echo` gibt einen Text aus. Mit `| sudo tee` schreibst du diesen Text in eine Datei. Das `sudo` braucht es, weil der Ordner `/opt` dem Administrator gehört.
```bash
echo "Diese Datei habe ich von Hand erstellt." | sudo tee /opt/willkommen.txt
cat /opt/willkommen.txt
```
`cat` zeigt den Inhalt einer Datei.

**Kontrolle:** `cat` zeigt die Zeile «Diese Datei habe ich von Hand erstellt.»

### Schritt 6: Eine Zeile anhängen
Jetzt hängst du eine zweite Zeile mit dem Datum an:
```bash
echo "Fertig eingerichtet am $(date)" | sudo tee -a /opt/willkommen.txt
cat /opt/willkommen.txt
```
`-a` hängt den Text an. Ohne `-a` würde `tee` die Datei überschreiben. `$(date)` wird durch das aktuelle Datum ersetzt.

**Kontrolle:** `cat` zeigt zwei Zeilen: deinen Satz und «Fertig eingerichtet am …» mit Datum.

### Schritt 7: VM verlassen und Stoppuhr stoppen
```bash
exit
```
Stoppe die Stoppuhr, sobald du wieder in PowerShell bist.

**Kontrolle:** Die Eingabezeile beginnt wieder mit `PS C:\...>`.

|---|---|
| Zeit für 1 Server | ____ Min. |
| Anzahl Befehle, die du getippt hast (ohne `tree --version` und `cat`) | ____ |

### Schritt 8: Fragen
Beantworte im Lernjournal:
1. Kreuze an: Was kann passieren, wenn du 10 Server von Hand einrichtest?
   - [ ] Ein Tippfehler, z. B. `htpo` statt `htop`.
   - [ ] Auf einem Server wird ein Schritt vergessen.
   - [ ] Die Server sind am Schluss nicht alle gleich.
   - [ ] Die Server werden schneller, weil du sie von Hand eingerichtet hast.
2. Ergänze den Satz: «Wenn ich nichts aufschreibe, weiss in einem Jahr niemand mehr, ________ auf dem Server eingerichtet wurde.»

### Schritt 9: Aufräumen
```powershell
multipass delete --purge hand
multipass list
```
**Kontrolle:** `multipass list` zeigt nur noch vm1.

## Wenn etwas nicht klappt

| Problem | Lösung |
|---------|--------|
| `Could not get lock …` oder `Waiting for cache lock …` | Die VM installiert direkt nach dem Start selbst Updates. 1–2 Minuten warten. Bricht der Befehl ab, gibst du ihn nochmals ein. |
| `Permission denied` | `sudo` vergessen. Den Befehl mit `sudo` davor wiederholen. Bei Schritt 5 und 6 steht `sudo` vor `tee`, nicht vor `echo`. |
| `tree: command not found` | Schritt 4 hat nicht geklappt. Ausgabe von `sudo apt install -y tree htop` lesen, Tippfehler prüfen. |
| `timed out waiting for initialization` | VM mit `multipass delete --purge hand` löschen und mit `multipass launch --timeout 600 --name hand` neu erstellen. |

## Zusatzaufgabe ⭐ htop ausprobieren
Mach diese Aufgabe **vor** Schritt 9 (Aufräumen). Starte in der VM `htop` (`multipass shell hand`, dann `htop`). Lies ab, wie viele CPUs die VM hat und wie viel RAM (`Mem`) belegt ist. Beende `htop` mit der Taste `q`. Vergleiche mit deinen Werten aus Auftrag 1.3.
