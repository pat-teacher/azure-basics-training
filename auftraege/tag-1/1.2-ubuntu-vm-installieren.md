# Auftrag 1.2: Ubuntu-Server-VM installieren

Stand: 19.10.2026 · Zeit: 90 Min. · Form: Einzelarbeit

## Ziel
Du kannst eine Linux-VM mit einem Typ-2-Hypervisor installieren und ihre Ressourcen bewusst festlegen. (K3)

## Voraussetzungen
- Auftrag 1.1 erledigt, Virtualisierung ist aktiviert
- VirtualBox ist installiert <!-- prüfen: Variante Hyper-V ergänzen, falls VirtualBox auf den Laptops nicht erlaubt ist -->
- ISO-Datei **Ubuntu Server LTS** liegt auf deinem Laptop (von der Kursleitung oder von [ubuntu.com/download/server](https://ubuntu.com/download/server))

## Ausgangslage
Die «Velo Zürich AG» braucht einen kleinen Linux-Server zum Testen. Du richtest ihn als VM auf deinem Laptop ein.

## Auftrag

### Schritt 1: VM anlegen
Erstelle in VirtualBox eine neue VM (**Maschine** > **Neu**) mit diesen Werten:

| Einstellung | Wert |
|-------------|------|
| Name | `vm-lokal-<kuerzel>` |
| ISO-Abbild | deine Ubuntu-Server-ISO |
| Unbeaufsichtigte Installation | **überspringen** (Häkchen setzen) |
| Arbeitsspeicher | 2048 MB |
| Prozessoren | 2 |
| Festplatte | 20 GB, dynamisch alloziert |

**Kontrolle:** Die VM erscheint links in der Liste mit Status «Ausgeschaltet».

### Schritt 2: Ubuntu installieren
Starte die VM und folge dem Installer. Wähle:
- Sprache: English (Fehlermeldungen lassen sich so leichter suchen)
- Tastatur: German (Switzerland)
- Netzwerk, Proxy, Mirror: Standardwerte übernehmen
- Speicher: «Use an entire disk»
- Profil: als Name dein Kürzel (keine echten Personendaten auf Screenshots), Servername `vm-lokal-<kuerzel>`, eigener Benutzername und Passwort
- **Install OpenSSH server: ankreuzen**
- Keine zusätzlichen Snaps

Nach dem Neustart: Falls der Installer nach dem Entfernen des Mediums fragt, drücke einfach `Enter`.

**Kontrolle:** Du siehst die Login-Aufforderung `vm-lokal-<kuerzel> login:` und kannst dich anmelden.

### Schritt 3: Die VM untersuchen
Führe in der VM diese Befehle aus und notiere jeweils das Ergebnis:

```bash
hostnamectl            # Name, Betriebssystem, Virtualisierung
systemd-detect-virt    # Welcher Hypervisor wird erkannt?
nproc                  # Anzahl CPUs
free -h                # Arbeitsspeicher
lsblk                  # Festplatten und Partitionen
ip a                   # Netzwerkschnittstellen und IP-Adressen
```

### Schritt 4: Fragen beantworten
1. Die VM sieht eine 20-GB-Festplatte. Wie gross ist die `.vdi`-Datei auf deinem Laptop? Warum ist das so?
2. `free -h` zeigt etwas weniger als 2 GB. Warum?
3. Welche IP-Adresse hat deine VM? Kannst du sie von Windows aus anpingen? (Die Erklärung folgt in Auftrag 1.3.)

## Zusatzaufgabe ⭐
Installiere die Updates in der VM und miss die Zeit:
```bash
time (sudo apt update && sudo apt upgrade -y)
```
Beobachte im Task-Manager von Windows, wie stark CPU und Festplatte belastet werden.
