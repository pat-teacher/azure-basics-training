# Auftrag 1.2: Multipass und deine erste VM

Zeit: 60 Min. · Form: Einzelarbeit

## Ziel
- Du kannst mit Multipass eine virtuelle Maschine (VM) erstellen, starten, stoppen und löschen. (K3)
- Du kannst einen Befehl in der VM ausführen. (K3)

## Voraussetzungen
- Auftrag 1.1 erledigt: Virtualisierung ist aktiviert, Windows Pro oder Education
- Internet (Multipass lädt Ubuntu selbst herunter, ca. 600 MB)

## Ausgangslage
Eine VM von Hand zu installieren dauert lange. **Multipass** ist ein kleines Programm von Canonical (der Firma hinter Ubuntu). Es erstellt eine fertige Ubuntu-VM mit einem einzigen Befehl. Im Hintergrund verwendet es den Hypervisor Hyper-V.

> [!TIP]
> Alle Befehle gibst du in **PowerShell** ein. Kopieren und Einfügen ist erlaubt.

## Auftrag

### Schritt 1: Multipass installieren
Lade Multipass für Windows herunter: [canonical.com/multipass/download/windows](https://canonical.com/multipass/download/windows). Starte den Installer und klicke dich durch.

Falls der Installer fragt, ob er Hyper-V einschalten soll: **Ja** wählen und den Laptop neu starten. <!-- prüfen: Verhalten des aktuellen Installers -->

**Kontrolle:** Öffne eine **neue** PowerShell und gib ein:
```powershell
multipass version
```
Du siehst zwei Zeilen mit Versionsnummern, z. B. `multipass 1.16.x`.

### Schritt 2: Welcher Hypervisor arbeitet im Hintergrund?
```powershell
multipass get local.driver
```
Der Befehl zeigt, welchen Hypervisor Multipass verwendet.

**Kontrolle:** Die Ausgabe ist `hyperv`. Notiere sie im Lernjournal.

### Schritt 3: Deine erste VM erstellen
```powershell
multipass launch --name vm1
```
`launch` erstellt und startet eine neue VM mit Ubuntu. `--name vm1` gibt ihr den Namen «vm1».

Beim ersten Mal lädt Multipass Ubuntu herunter. Das dauert einige Minuten. Solange sich die Anzeige bewegt, ist alles in Ordnung – **nicht abbrechen**.

**Kontrolle:** Am Schluss steht `Launched: vm1`.

### Schritt 4: Welche VMs gibt es?
```powershell
multipass list
```
`list` zeigt alle deine VMs.

**Kontrolle:** Du siehst eine Zeile mit `vm1`, Status `Running` und einer IP-Adresse.

### Schritt 5: In der VM arbeiten
```powershell
multipass shell vm1
```
`shell` öffnet eine Kommandozeile **in** der VM. Du arbeitest jetzt in Ubuntu, nicht mehr in Windows.

**Kontrolle:** Die Eingabezeile sieht jetzt so aus: `ubuntu@vm1:~$`

Gib in der VM diesen Befehl ein:
```bash
lsb_release -a
```
Er zeigt, welche Ubuntu-Version in der VM läuft. Notiere die Version.

Verlasse die VM wieder:
```bash
exit
```
**Kontrolle:** Du bist zurück in PowerShell (`PS C:\...>`).

### Schritt 6: Stoppen und wieder starten
```powershell
multipass stop vm1
multipass list
multipass start vm1
multipass list
```
**Kontrolle:** Nach `stop` steht bei vm1 `Stopped`, nach `start` wieder `Running`.

### Schritt 7: Fragen
Beantworte im Lernjournal:
1. Welcher Befehl erstellt eine neue VM?
2. Woran erkennst du, ob du gerade in Windows oder in der VM bist?
3. Welchen Hypervisor verwendet Multipass auf deinem Laptop?

> [!IMPORTANT]
> **vm1 noch nicht löschen.** Du brauchst sie in den Aufträgen 1.6 und ⭐ 1.7. Gelöscht wird sie am Schluss von Auftrag 1.6.

## Wenn etwas nicht klappt

| Problem | Lösung |
|---------|--------|
| `multipass` wird nicht gefunden | PowerShell schliessen und neu öffnen. Hilft das nicht: Laptop neu starten. |
| `launch` bricht mit «timed out» ab (auch `timed out waiting for initialization`) | Mit `multipass list` prüfen, ob eine halbe VM existiert. Diese löschen: `multipass delete --purge vm1`. Dann `launch` nochmals starten, mit mehr Zeit: `multipass launch --timeout 600 --name vm1`. |
| Fehler mit «Hyper-V» | Kursleitung holen. Hyper-V ist evtl. ausgeschaltet. |
| Multipass reagiert gar nicht mehr | Laptop neu starten. Das hilft fast immer. |

Klappt es auf deinem Laptop gar nicht: Arbeite mit deinem Partner auf dessen Laptop weiter und notiere es im Lernjournal.

## Zusatzaufgabe ⭐
