# Auftrag 1.3: Wie viel CPU und RAM bekommt eine VM?

Zeit: 30 Min. · Form: Einzelarbeit

## Ziel
- Du kannst einer VM beim Erstellen CPU, Arbeitsspeicher (RAM) und Festplatte zuweisen. (K3)
- Du kannst in der VM prüfen, was sie bekommen hat. (K3)

## Voraussetzungen
- Auftrag 1.2 erledigt, Multipass läuft

## Ausgangslage
Bei der «Velo Zürich AG» braucht nicht jeder Server gleich viel Leistung. Ein kleiner Testserver braucht wenig, ein Datenbankserver mehr. Bei einer VM legst du das selbst fest.

## Auftrag

### Schritt 1: Eine kleine VM erstellen
```powershell
multipass launch --name klein --cpus 1 --memory 1G --disk 5G
```
Die Optionen bedeuten:

| Option | Bedeutung |
|--------|-----------|
| `--cpus 1` | 1 virtueller Prozessor (vCPU) |
| `--memory 1G` | 1 Gigabyte Arbeitsspeicher |
| `--disk 5G` | 5 Gigabyte Festplatte |

**Kontrolle:** `Launched: klein`. Diesmal geht es schneller, weil Ubuntu schon heruntergeladen ist.

### Schritt 2: Nachschauen, was die VM bekommen hat
Mit `multipass exec` führst du einen einzelnen Befehl in der VM aus, ohne dich einzuloggen:

```powershell
multipass exec klein -- nproc
multipass exec klein -- free -h
multipass exec klein -- df -h /
```

| Befehl | zeigt … |
|--------|---------|
| `nproc` | Anzahl Prozessoren |
| `free -h` | Arbeitsspeicher (Zeile `Mem`, Spalte `total`) |
| `df -h /` | Festplatte (Spalte `Size`) |

Trage die Werte ein:

| | VM «klein» |
|---|---|
| Prozessoren | |
| Arbeitsspeicher | |
| Festplatte | |

**Kontrolle:** Die Werte passen ungefähr zu 1 CPU, 1 GB, 5 GB. Etwas weniger als 1 GB RAM ist normal – ein Teil ist für Ubuntu selbst reserviert.

### Schritt 3: Vergleich mit deinem Laptop
Schau in deinem Lernjournal aus Auftrag 1.1 nach: Wie viele logische Prozessoren hat dein Laptop?

Beantworte:
1. Wie viele VMs wie «klein» könnten gleichzeitig laufen, wenn jede VM einen eigenen Prozessor bräuchte?
2. Kreuze an: Was passiert, wenn alle VMs zusammen mehr Prozessoren bekommen, als der Laptop hat?
   - [ ] Die VMs starten gar nicht.
   - [ ] Die VMs teilen sich die echten Prozessoren abwechselnd. Unter Volllast wird es langsam.
   - [ ] Der Laptop baut automatisch neue Prozessoren ein.

### Schritt 4: Aufräumen
Die VM «klein» brauchst du nicht mehr.
```powershell
multipass delete --purge klein
multipass list
```
`delete --purge` löscht die VM endgültig.

**Kontrolle:** «klein» erscheint nicht mehr in der Liste. vm1 ist noch da.

## Erwartetes Ergebnis
Im Lernjournal: Tabelle aus Schritt 2 und Antworten aus Schritt 3.

## Zusatzaufgabe ⭐ Mehr zuweisen, als da ist
Versuche, eine VM mit **mehr** Prozessoren zu erstellen, als dein Laptop logische Prozessoren hat. Beispiel bei 8 logischen Prozessoren:
```powershell
multipass launch --name zuviel --cpus 12 --memory 1G
```
Klappt es, oder kommt eine Fehlermeldung? Beides ist ein gültiges Ergebnis. Mach einen Screenshot und lösche die VM danach (`multipass delete --purge zuviel`), falls sie erstellt wurde.
