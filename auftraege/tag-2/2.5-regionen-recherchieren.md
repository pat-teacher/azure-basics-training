# Auftrag 2.5: Azure-Regionen recherchieren

Zeit: 30 Min. · Form: Partnerarbeit

## Ziel
- Du kannst zu einer Region nachschlagen, ob sie Verfügbarkeitszonen (Availability Zones) hat und welches ihr Regionspaar (Region Pair) ist. (K1)
- Du kannst anhand von zwei Bedingungen eine passende Region bestimmen. (K3)

## Voraussetzungen
- Input «Aufbau von Azure» gehört
- Deine Liste der erlaubten Regionen aus Auftrag 2.2
- Theorie zum Nachlesen: [Kapitel 3 Aufbau von Azure](../../theorie/03-azure-aufbau.md)
- Lernjournal: Ordner `tag-2/2.5-regionen-recherchieren`

## Ausgangslage
Die Velo Zürich AG plant ihren Webshop in Azure. Die Geschäftsleitung hat zwei Bedingungen:
1. Die Daten der Kundinnen und Kunden bleiben in der **Schweiz**.
2. Fällt ein Rechenzentrum aus, soll der Webshop weiterlaufen.

Du und dein Partner sucht die passende Region.

**Kurz wiederholt:**
- **Region:** Gebiet mit Rechenzentren, z. B. Switzerland North (Zürich)
- **Verfügbarkeitszone:** unabhängiger Teil einer Region mit eigenem Strom, eigener Kühlung und eigenem Netz
- **Regionspaar:** zwei Regionen, die sich bei einem Grossausfall gegenseitig absichern

## Auftrag

### Schritt 1: Die Liste der Regionen öffnen
Öffne auf Microsoft Learn die Seite [Liste der Azure-Regionen](https://learn.microsoft.com/de-de/azure/reliability/regions-list).

**Kontrolle:** Du siehst eine Tabelle mit Regionen. Es gibt Spalten zu Standort (Geography), Verfügbarkeitszonen (Availability Zones) und Regionspaar (Paired region). <!-- prüfen: Stand 28.10.2026 – Spaltennamen der Seite -->

### Schritt 2: Vier Regionen vergleichen
Füllt die Tabelle aus.

| Region | Land | Verfügbarkeitszonen (Availability Zones)? (ja/nein) | Regionspaar (Region Pair) |
|--------|------|:---:|-------------|
| Switzerland North | | | |
| Switzerland West | | | |
| West Europe | | | |
| Germany West Central | | | |

> [!TIP]
> Mit `Ctrl` + `F` findest du eine Region auf der Seite schneller.

**Kontrolle:** Alle 12 Felder der Tabelle sind ausgefüllt.

### Schritt 3: Die Region für die Velo Zürich AG
Kreuzt an, welche Region beide Bedingungen erfüllt.

- [ ] Switzerland North
- [ ] Switzerland West
- [ ] West Europe
- [ ] Germany West Central

Begründet eure Wahl in 1–2 Sätzen.

**Kontrolle:** Eure Begründung nennt beide Bedingungen: Schweiz und Ausfall eines Rechenzentrums.

### Schritt 4: Und in deinem Abonnement?
Vergleiche mit deiner Liste der erlaubten Regionen aus Auftrag 2.2. Kreuze an:

- [ ] Die gewählte Region ist in meinem Abonnement (Subscription) erlaubt.
- [ ] Die gewählte Region ist in meinem Abonnement (Subscription) **nicht** erlaubt. Meine Kursregion ist: ______________

**Kontrolle:** Genau ein Kreuz. Die Kursregion stimmt mit deinem Eintrag aus Auftrag 2.2 überein.

### Schritt 5: Wozu ein Regionspaar?
Ergänze den Satz: Fällt die ganze Region Switzerland North aus, kann die Velo Zürich AG ihre Daten in der Region ______________ wiederherstellen. Die Daten bleiben dabei in der ______________.

**Kontrolle:** Die Region in der ersten Lücke steht in deiner Tabelle aus Schritt 2 als Regionspaar (Region Pair) von Switzerland North.

## Zusatzaufgabe ⭐
Die Azure CLI kennt die Regionspaare (Region Pairs) auch. Gib in der Cloud Shell ein:
```bash
az account list-locations --query "[?metadata.regionCategory=='Recommended'].{Name:name, Anzeige:displayName, Paar:metadata.pairedRegion[0].name}" --output table
```
`--query` wählt nur die empfohlenen Regionen aus und zeigt drei Spalten: kurzer Name, Anzeigename und Regionspaar (Region Pair). Vergleicht das Ergebnis mit eurer Tabelle aus Schritt 2.
