# Auftrag 2.1: IaaS, PaaS oder SaaS?

Zeit: 35 Min. · Form: Partnerarbeit

## Ziel
- Du kannst Dienste den Servicemodellen (Service Models) IaaS, PaaS und SaaS zuordnen. (K2)
- Du kannst sagen, wer bei welchem Modell das Betriebssystem verwaltet. (K2)
- Du kannst öffentliche Cloud (Public Cloud), private Cloud (Private Cloud) und hybride Cloud (Hybrid Cloud) unterscheiden. (K2)

## Voraussetzungen
- Input «Vom Hypervisor zum Hyperscaler» gehört
- Theorie zum Nachlesen: [Kapitel 2 Cloud-Grundlagen](../../theorie/02-cloud-grundlagen.md)
- Lernjournal: Ordner `tag-2/2.1-servicemodelle` (jede Person in ihrem eigenen Lernjournal)

## Ausgangslage
Die «Velo Zürich AG» verkauft Velos in zwei Läden und will online wachsen. Die Geschäftsleitung hört überall «Cloud», versteht aber die Abkürzungen nicht. Du und dein Partner bringt Ordnung hinein.

> [!TIP]
> Merkhilfe Pizza: **IaaS** = Küche mit Ofen mieten, **PaaS** = Lieferdienst backt nach deinem Rezept, **SaaS** = Restaurant.

## Auftrag

### Schritt 1: Dienste zuordnen
Setzt pro Zeile ein Kreuz. «Selbst betrieben» (On Premises) heisst: läuft auf eigener Hardware, nicht bei einem Cloud-Anbieter.

| Dienst | Selbst betrieben | IaaS | PaaS | SaaS |
|--------|:---:|:---:|:---:|:---:|
| Azure Virtual Machines | | | | |
| Microsoft Teams | | | | |
| Azure App Service (Plattform für eigene Web-Apps) | | | | |
| Deine Multipass-VM von Tag 1 | | | | |
| Azure SQL Database (Datenbank, Microsoft macht Updates und Backups) | | | | |
| Outlook im Browser (Microsoft 365) | | | | |
| Azure Virtual Network | | | | |
| Ein Server im Keller der Velo Zürich AG | | | | |
| OneDrive | | | | |
| Azure Managed Disks (Festplatten für VMs) | | | | |

**Kontrolle:** Vergleicht mit dem Nachbarteam. Wo seid ihr euch nicht einig? Markiert diese Zeilen.

### Schritt 2: Wer verwaltet was?
Die Velo Zürich AG will einen Webshop betreiben. Kreuzt an, wer sich jeweils um das **Betriebssystem** (Updates, Sicherheitslücken) kümmert.

| Variante | Velo Zürich AG | Anbieter (Microsoft bzw. Shopify) |
|----------|:---:|:---:|
| Webshop auf einer Azure-VM (IaaS) | | |
| Webshop in Azure App Service (PaaS) | | |
| Fertiger Online-Shop zum Mieten, z. B. Shopify (SaaS) | | |

Und wer ist bei **allen drei Varianten** für die Daten der Kundinnen und Kunden verantwortlich? Kreuzt an:

- [ ] Microsoft
- [ ] die Velo Zürich AG
- [ ] je nach Modell verschieden

**Kontrolle:** In der Tabelle hat jede Zeile genau ein Kreuz. Bei der Frage darunter ist genau eine Antwort angekreuzt.

### Schritt 3: Die fünf Merkmale der Cloud
Ordnet jeder Aussage ein Merkmal zu. Schreibt den Buchstaben in die Tabelle. Jeder Buchstabe kommt genau einmal vor.

**A** Selbstbedienung auf Abruf · **B** Zugriff über das Netz · **C** Ressourcen-Pool · **D** Schnelle Elastizität · **E** Messbarer Dienst

| Aussage | Merkmal |
|---------|:---:|
| Im Dezember braucht der Webshop doppelt so viel Leistung, im Januar wieder weniger. | |
| Auf der Rechnung steht genau, wie viele Stunden die VM gelaufen ist. | |
| Die Informatikerin erstellt um 22 Uhr eine VM, ohne jemanden anzurufen. | |
| Die VM der Velo Zürich AG läuft auf demselben Server wie VMs anderer Firmen. | |
| Der Lehrling verwaltet die Cloud vom Laptop zu Hause über den Browser. | |

**Kontrolle:** Jeder Buchstabe A bis E steht genau einmal in der Tabelle.

### Schritt 4: Öffentlich, privat oder hybrid?
Kreuzt an.

| Situation | öffentlich | privat | hybrid |
|-----------|:---:|:---:|:---:|
| Die Velo Zürich AG nutzt Microsoft 365. Die Buchhaltung läuft weiter auf dem Server im Keller. | | | |
| Eine Bank betreibt in ihren eigenen Räumen eine Cloud, nur für sich selbst. | | | |
| Ein Start-up hat keinen eigenen Server. Alles läuft in Azure. | | | |

**Kontrolle:** Jede Spalte hat genau ein Kreuz.

### Schritt 5: Eure Empfehlung
Die Velo Zürich AG hat **keine eigene Informatikabteilung**. Sie will einen Online-Shop so schnell wie möglich und mit wenig Aufwand. Kreuzt an und ergänzt den Satz.

- [ ] IaaS
- [ ] PaaS
- [ ] SaaS

«Dieses Modell passt, weil die Velo Zürich AG sich dann nicht um ______________ kümmern muss.»

**Kontrolle:** Euer Satz nimmt Bezug auf «keine eigene Informatikabteilung».
