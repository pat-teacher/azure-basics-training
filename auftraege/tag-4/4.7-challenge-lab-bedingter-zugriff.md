## Ausgangslage
Heute hast du mit der NSG festgelegt, wer **ins Netz** deiner VM darf: nach IP-Adresse und Port. Die Velo Zürich AG will auch festlegen, wer sich **anmelden** darf, zum Beispiel am Azure-Portal. Das regelt der **bedingte Zugriff** (Conditional Access) in Microsoft Entra ID:
- *wer:* Benutzer oder Gruppen
- *wann:* Bedingungen, z. B. von wo die Anmeldung kommt oder mit welchem Gerät
- *dann:* blockieren oder nur mit Multi-Faktor-Authentifizierung (MFA) erlauben

In deinem Abonnement (Subscription) für Azure for Students hast du keine Rechte in Microsoft Entra ID. Darum übst du in einem **Challenge Lab**, wie in Auftrag 2.7.

> [!IMPORTANT]
> Ein Lab lässt sich nur eine begrenzte Anzahl Male starten und läuft nach einer bestimmten Zeit ab. Starte es erst, wenn du mindestens 40 Minuten Zeit hast. <!-- prüfen: Stand 28.10.2026 – laut Skillable-FAQ für MSLE 10 Starts pro Modul -->

## Auftrag

### Schritt 1: Anmelden
1. Öffne [msle.learnondemand.net](https://msle.learnondemand.net/).
2. Hast du schon ein Skillable-Konto? Klicke auf **Einloggen** > **Skillable Account**.
3. Ist die Klasse aus dem Kurskanal neu für dich? Klicke stattdessen auf **Mit dem Schulungsschlüssel registrieren** und gib den Trainingsschlüssel dieser Klasse ein, wie in Auftrag 2.7, Schritt 1.

**Kontrolle:** Du siehst die Seite der Klasse mit einer Liste von Labs.

### Schritt 2: Lab starten
Öffne das Lab zum bedingten Zugriff (Conditional Access), das die Kursleitung angibt. Klicke auf **Starten** (Launch). <!-- prüfen: Klasse und genauer Lab-Name -->

**Kontrolle:** Links öffnet sich die Lab-Umgebung, rechts die Anleitung.

### Schritt 3: Lab bearbeiten
Bearbeite die Aufgaben in der Anleitung. Eine Person bedient, die andere liest vor und kontrolliert. Wechselt nach jeder Aufgabe.

**Kontrolle:** Am Ende zeigt das Lab, welche Aufgaben erfüllt sind.

### Schritt 4: Wer – wann – dann
Fülle für eine Richtlinie (Policy) aus dem Lab die Tabelle aus:

| wer: Benutzer oder Gruppe | wann: Bedingung | dann: Zugriff |
|---------------------------|-----------------|---------------|
| | | |

### Schritt 5: NSG oder bedingter Zugriff?
Kreuze an, womit die Velo Zürich AG die Anforderung umsetzt.

| Anforderung | NSG | bedingter Zugriff (Conditional Access) |
|-------------|:---:|:--------------------------------------:|
| SSH auf den Webserver nur aus dem Firmennetz | | |
| Anmeldung am Azure-Portal nur mit MFA | | |
| Port 80 für alle im Internet öffnen | | |
| Keine Anmeldung aus dem Ausland | | |
