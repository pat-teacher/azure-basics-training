# Auftrag 4.8: Werkzeuge für Tag 5 – Azure CLI und Visual Studio Code

Zeit: 20 Min. · Form: Einzelarbeit

## Ziel
- Du kannst die Azure CLI und Visual Studio Code mit `winget` installieren. (K3)
- Du kannst dich mit der Azure CLI auf deinem Laptop bei Azure anmelden. (K3)

## Voraussetzungen
- Laptop mit Windows und Adminrechten (wie bei Multipass an Tag 1)
- Internetzugang
- Lernjournal: Ordner `tag-4/4.8-werkzeuge-fuer-tag-5`

## Ausgangslage
Bis jetzt hast du die Azure CLI in der Cloud Shell verwendet. Am nächsten Kurstag schreibst du Dateien für Bicep und cloud-init. Die sollen auf deinem Laptop gespeichert bleiben. Darum arbeitest du an Tag 5 mit **Visual Studio Code** (einem Editor für Code) und der Azure CLI auf deinem Laptop.

Du installierst heute, damit am nächsten Kurstag alles bereit ist. Wenn etwas nicht klappt, bleibt so Zeit, es zu lösen.

`winget` ist die Paketverwaltung von Windows: Sie installiert Programme mit einem Befehl, wie `apt` in Ubuntu.

## Auftrag

### Schritt 1: winget prüfen (PowerShell)
Öffne die **PowerShell** auf deinem Laptop.
```powershell
winget --version
```

**Kontrolle:** Die Ausgabe ist eine Versionsnummer, z. B. `v1.9.25200`.

### Schritt 2: Azure CLI installieren (PowerShell)
```powershell
winget install --exact --id Microsoft.AzureCLI --accept-source-agreements --accept-package-agreements
```
`--exact --id` wählt genau dieses Paket. Die zwei `--accept-…`-Optionen bestätigen die Lizenzbedingungen, damit winget nicht nachfragt. Fragt Windows «Möchten Sie zulassen, dass …», klicke auf **Ja**. Die Installation dauert 1–3 Minuten.

**Kontrolle:** Die letzte Zeile ist `Successfully installed`.

### Schritt 3: Visual Studio Code installieren (PowerShell)
```powershell
winget install --exact --id Microsoft.VisualStudioCode --accept-source-agreements --accept-package-agreements
```

**Kontrolle:** Die letzte Zeile ist `Successfully installed`.

### Schritt 4: Neues Fenster, Versionen prüfen (PowerShell)
Schliesse die PowerShell und öffne sie **neu**. Erst ein neues Fenster findet die neuen Programme.
```powershell
az version
code --version
```

**Kontrolle:** `az version` zeigt eine Liste, die mit `"azure-cli": "2.…"` beginnt. `code --version` zeigt eine Versionsnummer, z. B. `1.95.3`.

### Schritt 5: Bicep vorbereiten (PowerShell)
```powershell
code --install-extension ms-azuretools.vscode-bicep
az bicep install
az bicep version
```
Die erste Zeile installiert die Bicep-Erweiterung in Visual Studio Code. Sie färbt Bicep-Dateien ein und schlägt beim Tippen vor. `az bicep install` lädt das Bicep-Werkzeug für die Azure CLI.

**Kontrolle:** Die erste Zeile endet mit `was successfully installed`. `az bicep version` zeigt `Bicep CLI version 0.…`.

### Schritt 6: Bei Azure anmelden (PowerShell)
```powershell
az login
```
Es öffnet sich ein Anmeldefenster von Windows (bei älteren Versionen der Browser). Melde dich mit dem Konto an, mit dem du Azure for Students verwendest. Fragt die PowerShell danach nach einem Abonnement (Subscription), tippe die Nummer von **Azure for Students** und drücke `Enter`.

Prüfe danach, welches Abonnement (Subscription) aktiv ist:
```powershell
az account show --output table
```

**Kontrolle:** In der Spalte `Name` steht `Azure for Students`.

### Schritt 7: Im Terminal von Visual Studio Code testen
1. Starte Visual Studio Code.
2. Öffne im Menü **Terminal** > **Neues Terminal** (New Terminal).
3. Tippe:
   ```powershell
   az account show --output table
   ```

**Kontrolle:** Dieselbe Ausgabe wie in Schritt 6. Du bist bereit für Tag 5.

## Wenn etwas nicht klappt

| Problem | Lösung |
|---------|--------|
| `winget` wird nicht erkannt | Im Microsoft Store das Programm **App-Installer** aktualisieren, dann PowerShell neu öffnen. |
| `az` oder `code` wird nicht erkannt | PowerShell schliessen und neu öffnen. Hilft das nicht: Laptop neu starten. |
| Installation bricht im Schulnetz ab | Nochmals versuchen. Sonst über den Hotspot deines Handys. |
| Das Anmeldefenster erscheint nicht | `az login --use-device-code`: Öffne die angezeigte Adresse im Browser und gib den Code ein. |
| `az login` meldet ein anderes Konto oder `No subscriptions found` | `az logout`, dann `az login` und das richtige Konto wählen. |
| `az account show` zeigt ein anderes Abonnement (Subscription) | `az account set --subscription "Azure for Students"` |
| `az bicep install` meldet einen Fehler | Kein Problem für heute: Die Azure CLI lädt Bicep am Tag 5 beim ersten Einsatz selbst. Notiere die Meldung. |

## Aufräumen
Nichts zu tun: Du hast in Azure nichts erstellt. Lass die Programme installiert.
