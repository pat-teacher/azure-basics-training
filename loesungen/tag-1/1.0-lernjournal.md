## Typische Fehler
| Problem | Ursache | Lösung |
|---------|---------|--------|
| Ordner `tag-1` fehlt, dafür Datei `tag-1` | Dateiname ohne `/README.md` | Datei löschen, neu mit `tag-1/README.md` |
| Kursleitung sieht das Repository nicht | Einladung an falschen Namen oder noch nicht angenommen | Mitgliederliste prüfen; Kursleitung nimmt Einladungen an |
| Repository öffentlich | Sichtbarkeit beim Erstellen nicht umgestellt | in den Einstellungen auf **Private** stellen |
| Screenshot als Datei im Repository statt im Text | hochgeladen statt eingefügt | geht auch: dann mit `![Text](bild.png)` im README verlinken |

## Hinweise für die Kursleitung
- Konto `pat-teacher` auf GitHub **und** GitLab bereithalten. Einladungen nach dem Auftrag annehmen: GitHub unter [github.com/notifications](https://github.com/notifications) bzw. per Mail; GitLab nimmt Einladungen bestehender Konten automatisch an.
- Lernende mit bestehendem Konto dürfen es verwenden. Wichtig ist nur: privates Repository, kein voller Name im Benutzernamen.
- Datenschutz: Die Konten liegen bei externen Anbietern (USA). Mit dem Auftraggeber klären, ob die Lernenden dort ein Konto anlegen dürfen; bei Minderjährigen ggf. Einverständnis. Alternative: Konto mit Schul-E-Mail-Adresse. <!-- prüfen -->
- Rückmeldungen gibst du als Kommentar zu einem Commit (GitHub/GitLab: Commit öffnen > Kommentar), oder mündlich im Coaching.
- Für Lernende ohne E-Mail-Zugang im Kurs: Auftrag 1.1 vorziehen, 1.0 in L8 nachholen. Einträge von 1.1 bis dahin in einer Textdatei sammeln.
