## Schritt 8
1. Richtig sind die ersten drei: Tippfehler, vergessener Schritt, Server nicht alle gleich. Die vierte Antwort ist falsch.
2. «… **was** (bzw. **wie**) auf dem Server eingerichtet wurde.»

## Zusatzaufgabe ⭐
`htop` zeigt oben links einen Balken pro CPU. Mit den Standardwerten von Multipass ist es 1 CPU und 1 GB RAM (`Mem`), davon sind ca. 200–300 MB belegt. Das passt zu den Werten aus Auftrag 1.3. <!-- prüfen: Standardwerte der aktuellen Multipass-Version -->

## Typische Fehler
| Problem | Ursache | Lösung |
|---------|---------|--------|
| `Could not get lock …` | Ubuntu installiert beim ersten Start automatisch Updates (unattended-upgrades). | 1–2 Minuten warten, Befehl wiederholen |
| `Permission denied` bei Schritt 5 | `sudo echo "…" > /opt/…` geschrieben: Die Umleitung `>` läuft ohne Adminrechte. | genau wie vorgegeben `echo … \| sudo tee …` verwenden |
| Datei hat nur eine Zeile | in Schritt 6 `tee` ohne `-a` → Datei überschrieben | Schritte 5 und 6 nochmals ausführen |

## Hinweise für die Kursleitung
- Der Auftrag ist absichtlich «langweilig». Er ist das Gegenstück zu Auftrag 1.5: dieselbe Einrichtung, einmal von Hand, einmal mit cloud-init.
- Danach folgt der Input «Automatisch statt von Hand – cloud-init». Zum Einstieg 2–3 gemessene Zeiten abfragen und auf 10 bzw. 100 Server hochrechnen.
- Wer schnell fertig ist, macht die Zusatzaufgabe oder legt in Auftrag 1.5 schon die Datei an (Schritte 1–2, noch keine VM starten).
- Die Tabelle aus Schritt 7 wird in Auftrag 1.5, Schritt 5 ergänzt.
