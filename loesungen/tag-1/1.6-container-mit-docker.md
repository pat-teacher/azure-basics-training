## Typische Fehler
| Problem | Ursache | Lösung |
|---------|---------|--------|
| `permission denied … docker.sock` | `sudo` vergessen | Befehl mit `sudo` wiederholen |
| `Conflict. The container name "/web" is already in use` | Container `web` gibt es schon | `sudo docker rm -f web`, dann neu starten |
| `port is already allocated` | ein anderer Container belegt Port 8080 | `sudo docker ps -a`, dann `sudo docker rm -f <name>` |
| `toomanyrequests` beim Herunterladen | Download-Limit von Docker Hub (viele Lernende, gleiche IP) | später nochmals versuchen <!-- prüfen: aktuelle Rate Limits --> |

## Hinweise für die Kursleitung
- Container sind laut Vertrag nur ein optionaler Überblick. Darum Zusatzauftrag.
- Plan B bei Download-Limit von Docker Hub: Image vom Google-Spiegel verwenden, z. B. `sudo docker run -d --name web -p 8080:80 mirror.gcr.io/library/nginx`. <!-- prüfen -->
