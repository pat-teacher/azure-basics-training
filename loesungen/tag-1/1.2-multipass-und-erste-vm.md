# Lösung 1.2: Multipass und deine erste VM

Stand: 19.10.2026

## Erwartete Ausgaben

```text
PS> multipass version
multipass   1.16.x
multipassd  1.16.x

PS> multipass get local.driver
hyperv

PS> multipass launch --name vm1
Launched: vm1

PS> multipass list
Name    State     IPv4            Image
vm1     Running   172.27.x.x      Ubuntu 26.04 LTS

ubuntu@vm1:~$ lsb_release -a
Distributor ID: Ubuntu
Description:    Ubuntu 26.04 LTS
...
```
<!-- prüfen: Standard-Image und Versionsnummern mit der aktuellen Multipass-Version kontrollieren -->

## Schritt 7
1. `multipass launch --name <name>`
2. Eingabezeile: In Windows `PS C:\...>`, in der VM `ubuntu@vm1:~$`.
3. `hyperv` (Hyper-V). Bei Windows Home mit VirtualBox: `virtualbox`.

## Zusatzaufgabe ⭐
`multipass info vm1` zeigt u. a. State, IPv4-Adresse, Release (Ubuntu-Version), CPU(s), Load, Disk usage, Memory usage.

## Typische Fehler
| Problem | Ursache | Lösung |
|---------|---------|--------|
| `multipass` nicht gefunden | PATH erst in neuer PowerShell aktiv | neue PowerShell öffnen, sonst Neustart |
| `launch failed: timed out` | erster Download dauert, oder Hyper-V Default Switch hängt | halbe VM löschen, erneut starten; evtl. `multipass launch --timeout 1000 --name vm1` |
| `cannot connect to the multipass socket` | Dienst «Multipass» läuft nicht | Neustart des Laptops |
| Netzwerkfehler beim Start | Netzwerkprofil «öffentlich», VPN | Netzwerk auf «privat» stellen, VPN trennen |

Ausführliche Fehlertabelle: TBZ M346, [KN01 Teil A3](https://gitlab.com/ch-tbz-it/Stud/m346/m346/-/blob/main/Kompetenznachweise/KN01.md).

## Hinweise für die Kursleitung
- Vorbereitung: Mit dem Auftraggeber klären, dass die Lernenden **Multipass installieren dürfen** (Adminrechte) oder dass es vorinstalliert ist. Sonst ist nichts vorzubereiten – Multipass lädt Ubuntu selbst.
- Beim ersten `launch` laden alle gleichzeitig ca. 600 MB. Im Schulnetz evtl. gestaffelt starten lassen (z. B. Reihe für Reihe). <!-- prüfen: Bandbreite im Kursraum -->
