# Lösung 3.5: Statische Website im Speicherkonto

Beispiel mit Kürzel `mm`.

## Schritt 1
Primärer Endpunkt z. B. `https://sttag3mm.z1.web.core.windows.net/`. Die Zahl nach `z` hängt von der Region ab.

## Schritt 2
Container `$web` neu vorhanden. Er wird beim Einschalten der statischen Website (Static Website) automatisch angelegt.

## Schritt 3 und 4
`index.html` und `404.html` im Container `$web`. Inhaltstyp `text/html` setzt das Portal beim Hochladen anhand der Endung.

## Schritt 5
- Primärer Endpunkt: Seite «Velo Zürich AG» mit Kürzel.
- `…/gibtsnicht`: Seite «Diese Seite gibt es nicht» (HTTP-Status 404).

Die Seite ist öffentlich, obwohl anonymer Zugriff auf das Speicherkonto (Storage Account) ausgeschaltet ist: Der Endpunkt der statischen Website (Static Website) ist ein eigener, immer öffentlicher Zugang nur für `$web`.

## Schritt 6

| Aussage | VM mit nginx (3.3) | statische Website (Static Website) (3.5) |
|---------|:---:|:---:|
| Betriebssystem installieren und aktuell halten | ✓ | |
| Port in der NSG öffnen | ✓ | |
| kostet jede Stunde Rechenleistung, auch ohne Besucher | ✓ | |
| Programm laufen lassen (Webshop mit Anmeldung) | ✓ | |

Eher **PaaS**: Ich liefere nur meine Dateien (meine Anwendung). Server, Betriebssystem und Webserver betreibt Microsoft. Nicht SaaS: Dort würde ich ein fertiges Produkt nutzen, nicht meine eigene Website darauf bringen. Die statische Website (Static Website) kostet nur Speicher und Abrufe, das sind bei einer kleinen Seite Bruchteile von Rappen.

## Schritt 7
Nach dem Löschen liefert die Adresse einen Fehler (DNS-Name existiert nicht mehr).

## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| `The requested content does not exist` (404 von Azure) | `index.html` fehlt in `$web` oder falsch geschrieben | Datei prüfen |
| Datei wird heruntergeladen | `index.html.txt` | im Editor «Alle Dateien», neu hochladen |
| Umlaute kaputt (`Ã¼`) | nicht als UTF-8 gespeichert | Editor: Codierung UTF-8 |
| Dateien in `dateien` statt `$web` hochgeladen | falscher Container | in `$web` hochladen |
| **Statische Website** (Static Website) fehlt im Menü | Speicherkonto (Storage Account) ist nicht vom Typ StorageV2 / Standard | nicht relevant bei Standardwerten aus 3.4 |
