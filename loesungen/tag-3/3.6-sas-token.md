# Lösung 3.6 ⭐: Datei per SAS-Token zeitlich begrenzt teilen

Beispiel mit Kürzel `mm`.

## Schritt 1
Berechtigungen **Lesen**, Ablauf 10 Minuten nach Start, Signaturmethode **Kontoschlüssel** (Standard). <!-- prüfen: Stand 08.11.2026 – Standard-Signaturmethode im Portal -->

## Schritt 2
```text
https://sttag3mm.blob.core.windows.net/dateien/preisliste.txt?sp=r&st=2026-11-08T09:10:00Z&se=2026-11-08T09:20:00Z&spr=https&sv=2022-11-02&sr=b&sig=…
```

| Teil | Bedeutung |
|------|-----------|
| `sp=r` | Berechtigung: read (lesen) |
| `st=…` | Start (UTC) |
| `se=…` | Ablauf (UTC), Schweiz im Winter UTC+1, im Sommer UTC+2 |
| `sr=b` | gilt für einen Blob |
| `sig=…` | Signatur, berechnet mit dem Zugriffsschlüssel (Access Key) |

## Schritt 3
Browser zeigt den Text der Preisliste. Ohne den Teil nach `?` kommt `PublicAccessNotPermitted` wie in 3.4.

## Schritt 4
```xml
<Error>
  <Code>AuthenticationFailed</Code>
  <Message>Server failed to authenticate the request. … Signature not valid in the specified time frame: Start […] - Expiry […] - Current […]</Message>
</Error>
```

## Schritt 5
1.

| Aktion | erlaubt | nicht erlaubt |
|--------|:---:|:---:|
| lesen vor Ablauf | ✓ | |
| ändern | | ✓ |
| andere Dateien im Container lesen | | ✓ |
| lesen nach Ablauf | | ✓ |

2. Der SAS-Link erlaubt nur das Nötigste (eine Datei, nur lesen) und läuft von selbst ab. Mit dem Zugriffsschlüssel (Access Key) könnte der Händler alles im Speicherkonto (Storage Account) lesen, ändern und löschen, und zwar ohne zeitliche Grenze, bis man den Schlüssel neu erzeugt.

## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| `AuthenticationFailed` sofort | Start in der Zukunft (Zeitzone verwechselt) oder Ablauf vor Start | Start «jetzt», Ablauf später |
| Link läuft nicht ab | Browser-Cache | `Ctrl` + `F5` |
| Nur Token kopiert (beginnt mit `sp=`) | falsches Feld | **Blob-SAS-URL** kopieren |

## Hinweise für die Kursleitung
- Prinzip der minimalen Rechte (Least Privilege) in einem Satz betonen: so wenig Rechte wie möglich, so kurz wie möglich.
- Ein SAS-Link lässt sich vor Ablauf nicht einzeln widerrufen (nur durch Neuerzeugen des Zugriffsschlüssels (Access Key)). Darum kurze Laufzeiten.
