# Lösung 3.2: Was gehört alles zur VM?

Beispiel mit Kürzel `mm`. Die Namen setzt das Portal automatisch, Zahlen und Zeichenfolgen sind bei allen anders.

## Schritt 3
Private IP `10.0.0.4` (erste freie Adresse im Subnetz (Subnet)), öffentliche IP (Public IP) wie in 3.1.

| Aussage | private IP | öffentliche IP (Public IP) |
|---------|:---:|:---:|
| Mit dieser Adresse per SSH angemeldet | | ✓ |
| Nur innerhalb des virtuellen Netzwerks (Virtual Network) erreichbar | ✓ | |
| Beim Partner dieselbe Adresse möglich | ✓ | |

Private Adressen wiederholen sich in jedem VNet, öffentliche gibt es weltweit nur einmal.

## Schritt 4
Sicherheitsregel (Security Rule) `SSH`, Priorität (Priority) `300`, Quelle (Source) **Any**, Port `22`, Aktion **Zulassen** (Allow). <!-- prüfen: Priorität -->

## Schritt 5
Status **Beendet (Zuordnung aufgehoben)** (Stopped (deallocated)). Die öffentliche IP (Public IP) bleibt gleich, weil sie vom Typ Standard und damit statisch ist.

| Ressource | kostet noch | kostet nichts |
|-----------|:---:|:---:|
| Rechenleistung (CPU, RAM) | | ✓ |
| OS-Datenträger (OS Disk) | ✓ | |
| öffentliche IP (Public IP) | ✓ | |

Lückentext: … dann kostet die Rechenleistung **weiterhin Geld**, weil **die Hardware für die VM reserviert bleibt** (Status «Beendet», nicht «Zuordnung aufgehoben»).

## Schritt 6
Löschen dauert 2–5 Minuten. `NetworkWatcherRG` darf bleiben.

## Zusatzaufgabe ⭐
Meist noch keine Kosten sichtbar: Die Kostenanalyse (Cost Analysis) zeigt Daten mit 8–24 Stunden Verzögerung.

## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| Nur fünf Ressourcen | Ansicht blendet Typen aus, oder VNet liegt in einer anderen Ressourcengruppe (Resource Group) | **Ausgeblendete Typen anzeigen** (Show hidden types); VNet über die Netzwerkschnittstelle (Network Interface) öffnen |
| Verwechslung D und E | «IP» kommt in beiden vor | NIC hat die private, die öffentliche IP (Public IP) ist eine eigene Ressource |
| VM nach `sudo poweroff` als «Beendet» | von innen heruntergefahren | im Portal **Beenden** (Stop) klicken → «Zuordnung aufgehoben» |

## Hinweise für die Kursleitung
- Der Auftrag liefert direkt die Antwort auf das Exit-Ticket («drei Ressourcen, die zusätzlich entstehen»).
- Schritt 5 ist die wichtigste Kostenregel des Kurses. Im Plenum nachfragen: «Wer hat den Unterschied zwischen ‹Beendet› und ‹Zuordnung aufgehoben› verstanden?»
- Vor Beginn von 3.3 kontrollieren, dass `rg-tag3-portal-…` gelöscht ist (vCPU-Kontingent).
