## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| `az` nicht gefunden | PATH erst in einem neuen Fenster aktualisiert | PowerShell bzw. Visual Studio Code neu starten |
| `winget` nicht gefunden | App-Installer veraltet | im Microsoft Store aktualisieren |
| Anmeldefenster erscheint nicht | Seit Azure CLI 2.61 meldet Windows über den Web Account Manager (WAM) an, nicht mehr über den Browser; das Fenster liegt manchmal hinter anderen | `az login --use-device-code`, Code auf der angezeigten Seite eingeben |
| falsches Konto (Schulkonto ohne Abonnement (Subscription)) | Browser war mit anderem Konto angemeldet | `az logout`, privates Browserfenster, `az login` |
| Installation blockiert | Schulnetz oder Richtlinie (Policy) auf dem Laptop | Handy-Hotspot; sonst an Tag 5 Cloud Shell als Ausweichlösung |
