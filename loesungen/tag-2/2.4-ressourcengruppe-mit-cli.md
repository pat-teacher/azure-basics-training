# Lösung 2.4: Dieselbe Ressourcengruppe mit der Azure CLI

Stand: 28.10.2026

Beispiel mit Kürzel `mm` und Kursregion `switzerlandnorth`.

## Schritt 1
Cloud Shell > Bash > **Kein Speicherkonto erforderlich** – ohne Speicherkonto (Storage Account), darum kostenlos – > Abonnement (Subscription) **Azure for Students** > **Anwenden**. Eingabezeile z. B. `mia [ ~ ]$`.

## Schritt 2
```text
$ az account show --output table
EnvironmentName    HomeTenantId    IsDefault    Name                State    TenantId
-----------------  --------------  -----------  ------------------  -------  ---------
AzureCloud         …               True         Azure for Students  Enabled  …
```

## Schritt 3
```text
$ az account list-locations --query "[?displayName=='Switzerland North']" --output table
DisplayName           Name                 RegionalDisplayName
--------------------  -------------------  --------------------------------
Switzerland North     switzerlandnorth     (Europe) Switzerland North
```

## Schritt 4
```bash
az group create --name rg-tag2-mm --location switzerlandnorth --tags kurs=azure-basics tag=2 owner=mm
```
```json
{
  "id": "/subscriptions/…/resourceGroups/rg-tag2-mm",
  "location": "switzerlandnorth",
  "managedBy": null,
  "name": "rg-tag2-mm",
  "properties": {
    "provisioningState": "Succeeded"
  },
  "tags": {
    "kurs": "azure-basics",
    "owner": "mm",
    "tag": "2"
  },
  "type": "Microsoft.Resources/resourceGroups"
}
```

## Schritt 5
```text
$ az group list --output table
Name        Location          Status
----------  ----------------  ---------
rg-tag2-mm  switzerlandnorth  Succeeded
```
Je nach Abonnement (Subscription) gibt es weitere, von Azure angelegte Gruppen (z. B. `NetworkWatcherRG`). Die bleiben stehen.

`az group show --name rg-tag2-mm --query tags` → die drei Tags als JSON.

## Schritt 6
Gleiche Region, gleiche Tags wie in 2.3.

## Schritt 7

| Aussage | Portal | Azure CLI |
|---------|:---:|:---:|
| zum ersten Mal sehen und verstehen | ✓ | |
| genau gleich zehnmal wiederholen | | ✓ |
| als Text im Lernjournal speichern | | ✓ |
| Anfrage geht an den Azure Resource Manager | ✓ | ✓ |

Warum gleich? Portal und CLI schicken ihre Anfrage an denselben Eingang, den Azure Resource Manager. Er erstellt die Ressource.

## Aufräumen
`az group delete --name rg-tag2-mm --yes` läuft ca. 30–60 Sekunden ohne Ausgabe. Danach zeigt `az group list --output table` die Gruppe nicht mehr.

## Zusatzaufgabe ⭐
`az resource list --resource-group rg-tag2-mm --output table` zeigt `vnet-tag2-mm` (Typ `Microsoft.Network/virtualNetworks`). Nach dem Löschen der Gruppe zeigt `az resource list --output table` das VNet nicht mehr: Löschen der Ressourcengruppe (Resource Group) löscht alles darin. `NetworkWatcherRG` (von Azure automatisch angelegt) bleibt stehen und ist kostenlos.

## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| `syntax error near unexpected token 'newline'` | `<kuerzel>` nicht ersetzt, Bash liest `<` und `>` als Umleitung | Platzhalter samt Klammern ersetzen |
| `RequestDisallowedByPolicy` | Region nicht erlaubt | kurzen Namen der Kursregion verwenden |
| `location … is not available` / `Invalid location` | Anzeigename statt kurzer Name (`"Switzerland North"`) | kurzen Namen aus Schritt 3 |
| Tags als ein einziger Tag (`"kurs": "azure-basics tag=2 …"`) | Anführungszeichen um alle Tags | ohne Anführungszeichen, durch Leerzeichen getrennt |
| Cloud Shell fragt nach Speicherkonto (Storage Account) und will eines erstellen | falsche Option gewählt | Abbrechen, neu öffnen, **Kein Speicherkonto erforderlich**; sonst Einstellungen > **Benutzereinstellungen zurücksetzen** |
| Einfügen mit `Ctrl` + `V` geht nicht | Terminal im Browser | `Ctrl` + `Shift` + `V` oder Rechtsklick > Einfügen |

## Hinweise für die Kursleitung
- In der Live-Demo des Inputs den ersten Start der Cloud Shell zeigen (Dialog «Kein Speicherkonto erforderlich»). Das ist die grösste Stolperstelle.
- Schritt 3: Wer eine andere Kursregion hat, muss den Anzeigenamen im `--query` anpassen (Gross-/Kleinschreibung und Leerzeichen genau wie im Portal). Ohne Filter hat die Liste über 80 Regionen.
- Vor L8 kontrollieren: `az group list -o table` bei allen ohne `rg-tag2-…`.
