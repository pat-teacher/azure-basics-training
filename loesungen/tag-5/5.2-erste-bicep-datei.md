# Lösung 5.2: Erste Bicep-Datei – ein Speicherkonto

Beispiel mit Kürzel `mm`.

## Schritt 3
```text
Resource and property changes are indicated with this symbol:
  + Create

The deployment will update the following scope:

Scope: /subscriptions/…/resourceGroups/rg-tag5-mm

  + Microsoft.Storage/storageAccounts/sttag5bicepmm [2023-05-01]
      …

Resource changes: 1 to create.
```

## Schritt 4 und 5
```powershell
az deployment group create --resource-group rg-tag5-mm --template-file main.bicep --parameters kuerzel=mm --query properties.outputs
```
```json
{
  "blobUrl": {
    "type": "String",
    "value": "https://sttag5bicepmm.blob.core.windows.net/"
  }
}
```
Beim zweiten Ausführen: dieselbe Ausgabe, kein Fehler.

## Schritt 6
```text
  ~ Microsoft.Storage/storageAccounts/sttag5bicepmm [2023-05-01]
    ~ sku.name: "Standard_LRS" => "Standard_GRS"

Resource changes: 1 to modify.
```
`az storage account show … --query sku.name --output tsv` → `Standard_GRS`.

## Schritt 7
`main.bicep` hat 11 Zeilen, `main.json` je nach Bicep-Version rund 50–60 Zeilen. <!-- prüfen: Zeilenzahl main.json -->

## Schritt 8
1. `+` wird erstellt, `~` wird geändert, `=` bleibt gleich, `-` wird gelöscht.
2. Mehrmals ausführen ergibt dasselbe Ergebnis wie einmal ausführen.
3. Zum Beispiel: «11 gegen 55 Zeilen. Bicep ist kürzer und lesbarer, das ARM-Template erzeugt Azure daraus selbst.»

## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| `StorageAccountAlreadyTaken` | Name global vergeben | Ziffern anhängen |
| `--parameters` vergessen | `kuerzel` hat keinen Standardwert | Azure fragt interaktiv nach oder meldet einen Fehler; Parameter angeben |
| what-if zeigt `- Delete` | `--mode Complete` verwendet | ohne `--mode` arbeiten (Standard ist Incremental) |
| Umstellung auf GRS scheitert | Region ohne Regionspaar (Region Pair) | Kursregion prüfen; in Switzerland North geht GRS <!-- prüfen --> |

## Hinweise für die Kursleitung
- Die Ressourcengruppe (Resource Group) `rg-tag5-<kuerzel>` bleibt für 5.3 stehen. Kosten: Rappenbeträge.
- Schritt 5 ist der Kern: Viele erwarten beim zweiten `create` einen Fehler. Kurz in der Klasse fragen, wer das vorhergesagt hätte.
- Die Live-Demo in Input 7 zeigt dasselbe. Wer schnell ist, kann den Auftrag in 30 Minuten schaffen und früher mit 5.3 beginnen.
