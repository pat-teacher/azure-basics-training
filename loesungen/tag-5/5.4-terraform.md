```text
Plan: 0 to add, 1 to change, 0 to destroy.
```
Nach `apply` meldet der nächste `plan`: `No changes. Your infrastructure matches the configuration.`

## Schritt 10
```text
Destroy complete! Resources: 2 destroyed.
```

## Schritt 11
1. `plan` ↔ `az deployment group what-if`, `apply` ↔ `az deployment group create`, `destroy` ↔ `az group delete`.
2. `2 to add`. Terraform schaut nur in die State-Datei. Ohne sie weiss es nichts von den Ressourcen. Ein `apply` würde dann mit «already exists» scheitern. Darum wird der State in Teams zentral gespeichert (Remote State, z. B. in einem Speicherkonto (Storage Account)).
3. Terraform, weil es mit Providern für viele Plattformen arbeitet: eine Sprache und dieselben Befehle für beide Clouds.

## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| `subscription ID could not be determined` | `ARM_SUBSCRIPTION_ID` fehlt (azurerm 4.x verlangt die ID) | Schritt 3 im aktuellen Terminal |
| Provider will Dienste registrieren und scheitert | Zeile `resource_provider_registrations = "none"` fehlt | ergänzen |
| `terraform` nicht gefunden | PATH erst in neuem Terminal | Terminal neu, sonst Visual Studio Code neu starten |
| `StorageAccountAlreadyTaken` | Name vergeben | Ziffern anhängen |
| `terraform.tfstate` im Lernjournal | Ordner komplett hochgeladen | Datei löschen; Speicherkonto (Storage Account) ist ohnehin gelöscht, Schlüssel damit ungültig |

## Hinweise für die Kursleitung
- Nicht im Vertragsumfang, darum nur ⭐. Für Lernstarke, die 5.3 früh fertig haben, oder als Hausaufgabe nach dem Kurs. Nicht während des Abschlussprojekts.
- Kosten: eine Ressourcengruppe (Resource Group) und ein Speicherkonto (Storage Account) für wenige Minuten, praktisch null.
- Vorab mit dem eigenen Konto testen: `winget install Hashicorp.Terraform` auf den Kurs-Laptops, azurerm 4.x mit Anmeldung über die Azure CLI und `resource_provider_registrations = "none"` im Student-Abo. <!-- prüfen -->
- Gesprächsanlass: State-Datei. Bicep braucht keine, weil Azure Resource Manager den Zustand kennt. Terraform braucht sie, weil es viele Plattformen gleich behandelt.
