## Schritt 11
1. `tofu plan` ↔ `az deployment group what-if`, `tofu apply` ↔ `az deployment group create`, `tofu destroy` ↔ `az group delete`.
2. `2 to add`. OpenTofu schaut nur in die State-Datei. Ohne sie weiss es nichts von den Ressourcen. Ein `apply` würde dann mit «already exists» scheitern. Darum wird der State in Teams zentral gespeichert (Remote State, z. B. in einem Speicherkonto (Storage Account)).
3. OpenTofu oder Terraform, weil sie mit Providern für viele Plattformen arbeiten: eine Sprache und dieselben Befehle für beide Clouds.
4. Zum Beispiel: «OpenTofu ist Open Source und für alle kostenlos nutzbar, Terraform hat seit 2023 eine Lizenz, die nicht mehr Open Source ist.»

## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| `subscription ID could not be determined` | `ARM_SUBSCRIPTION_ID` fehlt (azurerm 4.x verlangt die ID) | Schritt 3 im aktuellen Terminal |
| Provider will Dienste registrieren und scheitert | Zeile `resource_provider_registrations = "none"` fehlt | ergänzen |
| `tofu` nicht gefunden | PATH erst in neuem Terminal, oder der Ordner mit den winget-Verknüpfungen (Links) fehlt im PATH | Terminal neu, sonst Visual Studio Code neu starten |
| Lernende tippen `terraform` statt `tofu` | Anleitungen im Internet verwenden oft Terraform | Befehl `tofu`, der Rest bleibt gleich |
| `StorageAccountAlreadyTaken` | Name vergeben | Ziffern anhängen |
| `terraform.tfstate` im Lernjournal | Ordner komplett hochgeladen | Datei löschen; Speicherkonto (Storage Account) ist ohnehin gelöscht, Schlüssel damit ungültig |

## Hinweise für die Kursleitung
- Nicht im Vertragsumfang, darum nur ⭐. Für Lernstarke, die 5.3 früh fertig haben, oder als Hausaufgabe nach dem Kurs. Nicht während des Abschlussprojekts.
- **Warum OpenTofu statt Terraform:** HashiCorp hat Terraform 2023 unter die Business Source License (BSL) gestellt, die nicht mehr Open Source ist. OpenTofu ist die Abspaltung (Fork) unter der Linux Foundation mit Open-Source-Lizenz (MPL 2.0). Für Schulungen und Lernende gibt es damit keine Lizenzfragen. Befehle, Dateien (`.tf`, HCL), Provider und State-Datei sind kompatibel; nur der Befehl heisst `tofu`.
- Kosten: eine Ressourcengruppe (Resource Group) und ein Speicherkonto (Storage Account) für wenige Minuten, praktisch null.
- Vorab mit dem eigenen Konto testen: `winget install --exact --id OpenTofu.Tofu` auf den Kurs-Laptops, azurerm 4.x mit Anmeldung über die Azure CLI und `resource_provider_registrations = "none"` im Student-Abo, Erweiterung für Visual Studio Code. <!-- prüfen -->
- Gesprächsanlass: State-Datei. Bicep braucht keine, weil Azure Resource Manager den Zustand kennt. OpenTofu braucht sie, weil es viele Plattformen gleich behandelt.
- Input 7 hat am Schluss optionale Folien ⭐ «Ausblick: Terraform und OpenTofu» für eine Erklärung im Plenum.
