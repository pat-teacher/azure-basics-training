# Lösung 5.1: Ubuntu-VM mit cloud-init in Azure

Beispiel mit Kürzel `mm` und Kursregion `switzerlandnorth`.

## Schritt 1 und 2
`cloud-init.yaml`:
```yaml
#cloud-config
package_update: true
packages:
  - nginx
write_files:
  - path: /var/www/html/index.html
    content: |
      <meta charset="utf-8">
      <h1>Velo Zuerich AG</h1>
      <p>Webserver von mm, eingerichtet mit cloud-init</p>
```

## Schritt 3 bis 5
```powershell
az group create --name rg-tag5-ci-mm --location switzerlandnorth --tags kurs=azure-basics tag=5 owner=mm
az vm create --resource-group rg-tag5-ci-mm --name vm-web-mm --image Ubuntu2404 --size Standard_B1s --admin-username azureuser --ssh-key-values $HOME\.ssh\id_ed25519.pub --public-ip-sku Standard --custom-data cloud-init.yaml
az vm open-port --resource-group rg-tag5-ci-mm --name vm-web-mm --port 80
```

## Schritt 6
Browser `http://<öffentliche-ip>`: «Velo Zuerich AG», «Webserver von mm, eingerichtet mit cloud-init».

## Schritt 7
```text
$ cloud-init status --long
status: done
extended_status: done
boot_status_code: enabled-by-generator
…
$ sudo tail -n 5 /var/log/cloud-init-output.log
…
Cloud-init v. 24.x finished at <Datum und Zeit>. Datasource DataSourceAzure [seed=/dev/sr0].  Up 98.35 seconds
```
<!-- prüfen: Ausgabe von cloud-init status --long auf Ubuntu 24.04 -->

## Schritt 8
1. In 3.3 waren es in der VM drei Befehle (`apt update`, `apt install`, `tee` für die Startseite), dazu die Anmeldung. Heute null: Alles steht in der Datei.
2. Nichts. cloud-init läuft nur beim ersten Start.
3. Die erste Zeile `#cloud-config` und die Einrückung. Bei einem YAML-Fehler fehlt nginx ganz.

## Zusatzaufgabe ⭐
```yaml
packages:
  - nginx
  - tree
…
runcmd:
  - date > /opt/eingerichtet-am.txt
```
`cat /opt/eingerichtet-am.txt` zeigt Datum und Zeit des ersten Starts.

## Typische Fehler

| Problem | Ursache | Lösung |
|---------|---------|--------|
| Website lädt nicht («Verbindung abgelehnt») | cloud-init noch nicht fertig (1–3 Min.), nginx noch nicht installiert. `write_files` läuft vor der Paketinstallation, darum erscheint nie die Standardseite von nginx. | warten, neu laden |
| nginx fehlt ganz | `#cloud-config` fehlt, Tabs statt Leerzeichen, Datei falsch gespeichert | Datei korrigieren, VM neu erstellen |
| `--ssh-key-values` Fehler | Pfad mit `~` statt `$HOME` in einem anderen Terminal, Schlüssel fehlt | `$HOME\.ssh\id_ed25519.pub`, Auftrag 1.6 |
| Seltsame Zeichen oder cloud-init scheitert | Umlaute in `cloud-init.yaml` | ae, oe, ue schreiben, Ressourcengruppe (Resource Group) löschen, neu |
| Befehl in der Cloud Shell ausgeführt | Gewohnheit von Tag 2–4 | geht auch, aber `cloud-init.yaml` muss dann in der Cloud Shell liegen. Besser im Terminal von Visual Studio Code. |

## Hinweise für die Kursleitung
- Tandem wie an Tag 4: Jede Person baut im eigenen Abonnement (Subscription).
- Zu Beginn prüfen, dass alle im Terminal von Visual Studio Code arbeiten und `az account show` **Azure for Students** zeigt.
- Wer 4.8 nicht geschafft hat, arbeitet ausnahmsweise in der Cloud Shell: Datei mit `code cloud-init.yaml` im Cloud-Shell-Editor anlegen und sofort ins Lernjournal kopieren.
- Bezug zu Tag 1 (Auftrag 1.5) herstellen: dieselbe Datei funktioniert mit Multipass und in Azure.
